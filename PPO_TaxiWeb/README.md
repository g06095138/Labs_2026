# Сайт «Служба такси» — ППО, ЛР0–ЛР5
Самостоятельная адаптация PPO-Findirector-Labs.docx под службу такси. Это веб-приложение, не WinForms. Формальные финансовые требования заменены предметными сценариями такси; подробности и ограничения — [docs/adaptation.md](docs/adaptation.md).

## Что сдавать
[Перечень артефактов](docs/artifacts.md), [спецификация](docs/requirements.md), [проектирование](docs/design.md), [данные](docs/data.md), [UI](docs/ui.md), [протокол проверок](docs/validation.md).
Документы Word — `docs/reports`, схемы и редактируемые PlantUML — `docs/diagrams`. Скриншоты реально проверенного сайта — `docs/test-results` (отдельно от проектного макета).

## Требования
.NET SDK 10.0.403 или совместимый .NET 10 SDK согласно global.json. Linux, Windows или macOS; отдельный сервер БД не нужен. Нужен доступ к NuGet при первом restore. Деньги — RUB, БД — SQLite.

## Сборка и тесты вне IDE
Из каталога с Taxi.sln:
```sh
dotnet restore Taxi.sln --locked-mode
dotnet build Taxi.sln -c Release --no-restore
dotnet test Taxi.sln -c Release --no-build --logger "trx;LogFileName=taxi-tests.trx"
dotnet run --project src/Taxi.Console -c Release --no-build
```
Консоль выводит 180.00 / 270.00 / 450.00 RUB (десятичный разделитель зависит от текущей культуры).

## Запуск для разработки
```sh
dotnet run --project src/Taxi.Web --urls http://127.0.0.1:5080
```
Браузер на своём компьютере: адрес 127.0.0.1, порт 5080. После остановки и повторного запуска с той же БД заказы сохраняются. По умолчанию файл `src/Taxi.Web/App_Data/taxi.db`; он игнорируется Git и отсутствует в архиве.

## Публикация и запуск без IDE
Публикация здесь — создание локальной папки сборки, не размещение в интернете:
```sh
dotnet publish src/Taxi.Web -c Release --no-restore -o artifacts/publish
cd artifacts/publish
dotnet Taxi.Web.dll --urls http://127.0.0.1:5080
```
Нужен ASP.NET Core Runtime 10 для запуска framework-dependent сборки. SQLite создаётся автоматически при первом запуске в App_Data относительно content root. Для явного пути передайте `--TaxiDb /полный/путь/taxi.db` (на Windows — свой абсолютный путь). Каталог должен быть доступен на запись.

## Учебные учётные записи
Общий демонстрационный пароль: `TaxiDemo!2026`.
| Логин | Роль |
|---|---|
| client / client2 | два независимых клиента |
| dispatcher | диспетчер |
| driver1 / driver2 / driver3 | три водителя |

Это специально опубликованные данные локального учебного стенда, не настоящие секреты. Не размещать сайт с этими учётными записями в открытом интернете. Управление пользователями, восстановление паролей, rate limiting, аудит действий и промышленное развёртывание не входят в учебный объём.
Роли проверяются сервером. Файл SQLite и ключи ASP.NET DataProtection должны сохраняться для устойчивой работы; локальные ключи не включаются в Git.

## Действия пользователя
Клиент: заполнить маршрут и данные → сравнить тарифы → выбрать → создать. Изменение поля скрывает прежнюю оценку. Диспетчер: выбрать свободного водителя → назначить заказу. Водитель: начать → завершить. «Обновить» перечитывает данные.

## Дополнительная браузерная проверка
`scripts/smoke_browser.py` использует Python + Playwright и локальный Chromium. Это дополнительный тест, не обязательная зависимость самого приложения. Запускать с чистой отдельной БД. Переменные TAXI_URL и CHROMIUM задают адрес и путь браузера. Программа создаёт два тестовых заказа; повторный запуск требует новой БД, иначе проверка точного количества закономерно не пройдёт.

## Архитектура
- Taxi.Domain — модель, валидация, decimal-расчёт.
- Taxi.Application — роли, сценарии, интерфейс ITaxiStore.
- Taxi.Infrastructure — SQLite, атомарные операции, хеширование паролей.
- Taxi.Web — Blazor Interactive Server; формулы не дублируются в Razor.
- Taxi.Console — демонстрация расчёта ЛР0.
- Taxi.Tests — xUnit, unit/integration, временные БД.

## Редактирование схем
Исходники `*.puml` открываются в PlantUML. Для генерации: `java -jar plantuml.jar -tsvg docs/diagrams/*.puml` и аналогично `-tpng`. Java/PlantUML не нужны для работы сайта. Макет ui-mockup.svg нарисован отдельно и не является скриншотом.

## GitLab
Создать отдельную папку TaxiWeb_Labs и перенести содержимое комплекта, сохранив структуру src/tests/docs. Не переносить bin, obj, App_Data, tools и приватные данные. Ранее загруженный Lab 0 относится к первому вводному заданию; этот комплект его не перезаписывает.
Исходная методичка требует ссылку на коммит или метку сдачи lab0…lab5. Не выдавать итоговый снимок за шесть последовательно выполненных исторических коммитов. Для каждой фактической сдачи указывать её реальный коммит и соответствующие файлы из docs/artifacts.md.
