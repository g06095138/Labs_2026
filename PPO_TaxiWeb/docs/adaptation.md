# Адаптация комплекта ППО к сайту «Служба такси»
Основание: PPO-Findirector-Labs.docx, предоставленный пользователем. Предметная область взята из курсовой «АИС Служба такси». Пояснение семинариста передано одногруппником: допускается собственная тема, итог — сайт.

Финансовые формулы, три месяца и задолженность не переносятся буквально: они описывают другой продукт. Сохраняются структура работ, архитектурные ограничения, проверяемость, порядок «спецификация → код → тесты», хранение и веб-интерфейс. Это самостоятельная адаптация; формального подтверждения преподавателя на конкретную замену требований нет.

| Исходный проект | Сайт такси |
|---|---|
| План и параметры месяцев | Заказ, маршрут и тариф |
| Расчёт одного месяца ЛР0 | Расчёт стоимости одной поездки |
| Прогноз и сравнение планов | Сравнение тарифов для одного маршрута и жизненный цикл заказа |
| Хранение планов | Хранение клиентов, водителей, тарифов и заказов |
| Финансовый директор | Клиент, диспетчер, водитель |
| Пересчёт после изменения параметров | Скрытие старой оценки при изменении расстояния/адресов |
| Decimal, точность копеек | Decimal, округление AwayFromZero; SQLite INTEGER копеек |
| Domain / Application / Infrastructure / UI | Те же четыре слоя, Blazor Web App, .NET 10, SQLite, xUnit |

В отличие от курсовой: WinForms/.NET 9/PostgreSQL заменены на Blazor/.NET 10/SQLite. Расстояние вводится пользователем (по умолчанию 4 км), чтобы расчёт, сравнение и пересчёт имели содержательный сценарий. Добавлены учётные записи ролей и серверная проверка принадлежности заказа: простой выбор роли из курсовой не обеспечивает разграничения доступа.

Архив Findirector-Lab0-Starter.zip и отдельный CFO-Spec-and-Starter не предоставлены. Исходный проект лектора и его исходные тесты не запускались; ЛР0 выполнена на самостоятельно разработанном ядре такси. Метки lab0…lab5 не созданы: комплект — итоговый снимок, а не вымышленная история шести сдач.
