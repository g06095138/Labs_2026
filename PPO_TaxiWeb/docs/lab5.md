# ЛР5. Веб-интерфейс
Blazor Web App (.NET 10, Interactive Server). Три ролевые области после входа: клиент, диспетчер, водитель. До реализации зафиксированы docs/ui.md и макет. Обработчики вызывают TaxiService; формула цены содержится только в Domain.

Сайт позволяет сравнить тарифы, оформить заказ, назначить водителя, начать и завершить поездку. После правки входа прежняя оценка скрывается. Серверная роль и идентификатор профиля извлекаются из cookie. Переходы имеют серверные проверки; кнопки скрываются в соответствии с доступными действиями.

Команды build/test/publish/run вне IDE приведены в README. Фактические результаты и скриншоты — validation.md и test-results. Для размещения в интернете нужны дополнительные эксплуатационные меры, учебные учётные записи предназначены только для локального стенда.
