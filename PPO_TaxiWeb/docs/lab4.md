# ЛР4. Хранение заказов
SQLite реализован в Taxi.Infrastructure через ITaxiStore. Схема создаётся при запуске, FK включены в соединении. Входные деньги/ставки сохраняются целыми копейками; расстояние — сотыми километра. Создание заказа и обновление клиента — одна транзакция. Назначение и завершение — транзакции с проверками состояния.

Повторный запуск Initialize не перезаписывает заказы. Обновление состояний существующего ID не добавляет дубликаты, другой заказ не меняется. Цена/ставки зафиксированы, результат сравнения не хранится.

Интеграционные тесты: Storage_RoundTripAndRestart, Storage_RoundsAndRetainsKopeck, Workflow_Completes, Assignment_IsAtomic, Assignment_ConcurrentRequests, Storage_ForeignKeysAndUniqueActive. Уточнённая ER-схема и поля — docs/data.md и diagrams/er.*. Отдельные рабочие БД из тестов в Git не включены.
