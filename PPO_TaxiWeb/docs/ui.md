# ЛР5. Спецификация интерфейса
## Экраны
/login — логин и пароль, POST с antiforgery; ошибка общая, без раскрытия существования логина. / — личная рабочая область; требуется вход. /logout — POST с antiforgery.

Клиент: ФИО, телефон, адрес подачи/назначения, расстояние; «Сравнить тарифы»; таблица базовой цены, переменной части и итога; выбор тарифа; «Создать заказ»; список своих заказов и «Обновить».
Диспетчер: все заказы, список свободных водителей, выбор водителя и «Назначить» для Created, «Обновить».
Водитель: только свои активные заказы; «Начать» для Assigned и «Завершить» для InProgress, «Обновить».

До подключения интерактивного сеанса форма заблокирована, чтобы введённые до гидратации значения не потерялись.

Изменение любого входного поля очищает оценку. Создание доступно после сравнения; сервер всё равно валидирует и рассчитывает независимо. При ошибке выводится «Поле: причина», старый результат не восстанавливается. При успешной операции список обновляется, повторное действие защищено статусом и флагом обработки кнопки.
Видимые элементы не заменяют проверку прав в сервисе. Клиент не передаёт роль и владельца заказа. Интерфейс русскоязычный, цены с двумя знаками и рублями.

## Макет
Отдельный docs/diagrams/ui-mockup.svg — проектный макет клиента и диспетчера, а не скриншот работающей программы. Экран водителя использует ту же таблицу и две кнопки переходов.

## Сквозная проверка
1. Войти клиентом, сравнить 4 км: 180/270/450; выбрать Комфорт, создать заказ 270.
2. Изменить расстояние на 10: старой оценки нет; пересчитать: 300/450/750.
3. Создать второй заказ; выйти. Войти диспетчером, назначить driver-1 первому заказу.
4. Войти driver1: начать и завершить свой заказ. driver2 не видит и не меняет чужой заказ.
5. Перезапустить сайт с тем же TaxiDb; клиент открывает сохранённые заказы, первый Completed, цена 270.
6. Ввести 0 км или пустой адрес: ошибка, число заказов не меняется.
7. Неверный пароль: отказ; без входа рабочая область недоступна.
Фактические результаты фиксируются отдельно в docs/validation.md, включая непройденные шаги.
