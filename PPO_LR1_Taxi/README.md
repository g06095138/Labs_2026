# ЛР1 — финансовое планирование службы такси
Отдельный комплект по ЛР1 из PPO-Findirector-Labs.docx. Предметная область — служба такси; плановая услуга — выполненная поездка. Все финансовые формулы и шесть П-Ф исходной методички сохранены.

## Что открыть
- docs/requirements.md — обязательная спецификация: цель, границы, словарь, план/месяц/результат; три сценария; восемь примеров; таблица соответствия.
- docs/diagrams/use-cases.puml — редактируемый PlantUML.
- docs/diagrams/use-cases.svg — обязательное изображение диаграммы.
- docs/diagrams/use-cases.png и .pdf — удобные копии.
- ЛР1_Такси_Требования.docx — копия спецификации для Word с диаграммой.
- docs/calculation-check.json — независимая проверка числовых ожиданий; это не результаты тестирования приложения.

## Что меняется относительно нашей прежней работы
Ранее сделанный сайт обслуживает реальные заказы. Эта ЛР1 специфицирует будущее финансовое расширение для руководителя. Оно не реализовано; код и БД существующего сайта не меняются. Общая нулевая диаграмма ролей не заменяется: новая Use Case относится именно к финансовому модулю.

## Сравнение с ЛР1 одногруппника
Состав обязательных файлов и структура задания одинаковы. У одногруппника — план рейсов на три дня и операционные показатели. Здесь — финансовый план службы такси на три месяца; денежные П-Б1–П-Б10 сохранены, включая оплату 0/50/100%, задолженность и кассовый разрыв. Это разные спецификации, не копия чужого проекта.

## Проверка и сдача
Контрольные таблицы независимо пересчитаны decimal, проверены числовые итоги и ссылки на требования. Исходник Use Case отрендерен PlantUML. Полный сайт для этих сценариев не запускался: финансового модуля ещё нет. Классы и ER появятся в ЛР2.

На GitHub комплект размещается отдельно, чтобы не перезаписать прежние файлы. Для GitLab загрузить распакованные docs и при желании Word в папку своей ЛР1; сохранить структуру docs/diagrams. Перед указанием готовности преподавателю проверить, что согласована именно финансовая часть службы такси. Реальный коммит сдачи указывается отдельно, чужие метки не используются.
