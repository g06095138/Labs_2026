# Лабораторная работа № 3 — KNN

Набор содержит ноутбук с выполненными ячейками, скрипт Python, исходный CSV и отчёт.

## Запуск

Откройте `Lab3_KNN_Titanic.ipynb` в Google Colab или Jupyter и выполните ячейки сверху вниз. CSV уже встроен в ноутбук, интернет для загрузки данных не нужен. Скрипт `lab3_knn.py` запускается из этой папки после установки зависимостей из `requirements.txt`.

Данные Titanic взяты из предыдущей лабораторной работы. В задаче прогнозируется `survived`; метрики и случайные состояния фиксируются в коде.
