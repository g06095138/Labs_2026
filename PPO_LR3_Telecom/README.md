# ЛР3. Прогноз и финансовые показатели оператора связи

Самостоятельный консольный проект C# / .NET 10, адаптированный по курсовой «БД „Учёт вызовов оператора связи“». Программа рассчитывает финансовый план оператора на три месяца и сравнивает два плана. Она работает на macOS, Windows и Linux.

## Что готово

- Проверка исходных данных целиком перед прогнозом.
- Выручка от минут связи и абонентской платы, переменные и постоянные расходы, прибыль, поступления, деньги и задолженность каждого месяца.
- Перенос денег и задолженности, продолжение после отрицательного остатка, потребность в начальном финансировании.
- Независимое сравнение двух планов, повторный расчёт без изменения входов.
- Консольная демонстрация и ввод плана из JSON; тесты xUnit.
- Спецификация, проектирование, диаграмма классов и пояснительный отчёт.

Это учебный прогноз по агрегированным входам. Детальная тарификация каждого звонка из курсовой, подключение PostgreSQL, регистрация и личные кабинеты сюда не входят. Постоянное хранение планов относится к ЛР4, веб-интерфейс — к ЛР5. Чтение JSON в ЛР3 служит способом передать исходные данные консоли.

## Запуск в VS Code на Mac

1. Установите .NET 10 SDK и расширение **C# Dev Kit** от Microsoft.
2. Распакуйте архив и откройте в VS Code папку **LR3_Telecom**, внутри которой находятся `TelecomFinance.sln`, `src`, `tests`, `examples`.
3. Дождитесь загрузки решения. Откройте `src/TelecomFinance.Console/Program.cs`.
4. Нажмите треугольник **▶** вверху справа или выберите **Выполнить → Запустить без отладки**. Если появится выбор проекта, выберите **TelecomFinance.Console**.
5. В панели «Запуск и отладка» также можно выбрать готовую конфигурацию демонстрации, расчёта плана B или сравнения и нажать F5.
6. Во вкладке «Терминал» появятся три плана: оплата 0%, 50%, 100% сразу, затем сравнение 0% и 50%. Программа завершается после вывода — это нормальная работа демонстрации.

Тесты без терминала: откройте значок колбы «Тестирование» слева и нажмите **Запустить все тесты**. При первом запуске нужен доступ к NuGet для загрузки зависимостей.

## Команды из папки с решением

```bash
dotnet restore TelecomFinance.sln --locked-mode
dotnet build TelecomFinance.sln -c Release --no-restore
dotnet run --project src/TelecomFinance.Console -c Release --no-build -- demo
dotnet test TelecomFinance.sln -c Release --no-build
```

Расчёт своего плана и сравнение:

```bash
dotnet run --project src/TelecomFinance.Console -- forecast examples/plan-b.json
dotnet run --project src/TelecomFinance.Console -- compare examples/plan-a.json examples/plan-b.json
```

Без аргументов запускается `demo`. После правки JSON повторно запустите `forecast`. В режиме отладки VS Code параметры запуска можно задать в конфигурации запуска; для готовой демонстрации это не требуется.

## Как прочитать контрольный результат

В каждом месяце обслуживаются 100 абонентов. У каждого 200 оплачиваемых минут по 5 ₽ и абонплата 500 ₽: средний счёт — 1500 ₽. Выручка оператора — 150000 ₽. Переменные расходы — 100 × 500 = 50000 ₽; постоянные — 70000 ₽; прибыль — 30000 ₽.

При оплате 0% сразу итоговая прибыль за три месяца равна 90000 ₽, но деньги после третьего месяца составляют −10000 ₽, долг клиентов — 150000 ₽. Самый большой дефицит возникает в первом месяце: 70000 ₽. При оплате 50% сразу прибыль та же, конечные деньги — 65000 ₽, долг — 75000 ₽, финансирование не требуется.

Прибыль и деньги различаются из-за отсрочки оплаты. Отрицательный прогнозный остаток помечается «Не хватает денег»; автоматический кредит не добавляется.
