# ER-модель оператора связи в нотации Чена

Перерисовка предоставленной логической схемы FinancialPlan / PlanMonth. Это отдельная предметная область; файлы службы такси не изменяются.

## Что сохранено
- FinancialPlan: plan_id (ключ), name, start_year, start_month. plan_id — непустой уникальный UUID; name после trim непусто.
- PlanMonth: month_index, active_clients, avg_minutes_per_client, avg_price_per_minute, monthly_fee_per_client, operational_costs, payment_rate_percent.
- У каждого плана ровно три месяца, индексы 1,2,3. Ключ строки месяца при переходе к таблицам: (plan_id,month_index).
- Все атрибуты обязательны. Диапазоны сохранены из изображения: start_year и годы всех трёх периодов 2020…2099; start_month 1…12; active_clients — целое ≥1; средние минуты ≥0; цена минуты >0; абонплата и расходы ≥0; процент 0…100.

## Обозначения Чена
FinancialPlan — обычная сущность с прямоугольником. plan_id подчёркнут сплошной линией. PlanMonth — слабая сущность с двойным прямоугольником: month_index идентифицирует месяц только внутри конкретного плана, поэтому является частичным ключом и подчёркнут пунктиром.

«Содержит» — идентифицирующая связь, двойной ромб. Участие обязательное с обеих сторон (двойные линии). Кратность 1:N дополнена ограничением ровно трёх месяцев.

PlanMonth.plan_id не дублируется овалом: на концептуальной схеме владелец задаётся связью. При переходе к таблицам внешний ключ plan_id и составной первичный ключ остаются такими же, как на исходной схеме. Нового глобального month_id не вводится.

Не добавлены вычисляемые MonthResult/ForecastResult, остатки денег и задолженности. Оперативные таблицы clients, calls, tariffs, payments в эту модель не входят.

## Файлы
- er.svg — основная векторная схема с корректным пунктирным подчёркиванием частичного ключа.
- er.png — изображение для просмотра и вставки в отчёт.
- er.pdf — версия для печати.
- er.puml — редактируемое описание Chen в PlantUML. Автоматическая раскладка и графика частичного ключа могут отличаться от вручную выровненной SVG.

Содержимое восстановлено по изображению пользователя; исходные документы и код системы оператора связи не проверялись.
