# ЛР2 — финансовое планирование службы такси
Комплект переделан по предоставленному примеру Forex: та же структура проектной документации, тема — служба такси и её финансовые планы. Содержание согласовано с нашей последней ЛР1 и кодом отдельного финансового модуля ЛР3.

## Файлы
- docs/requirements.md — цель, словарь, объекты, требования и правила, три сценария, восемь приёмочных примеров, соответствие.
- docs/design.md — архитектура, классы, формулы, пять контрактов, SRP/DIP, ручной расчёт, соответствие ЛР2.
- docs/data.md — логические сущности, поля, ключи, кратности, сохранение и целостность.
- docs/diagrams/components.*, domain.*, er.* — три обязательные схемы: PUML, SVG, PNG и PDF.
- docs/diagrams/use-cases.* — копия предыдущей диаграммы ЛР1 для связи требований.
- ЛР2_Такси_Проектирование.docx — документ Word со спецификацией и схемами.

Компонентная схема и диаграмма классов оформлены в стиле предоставленных изображений: прямоугольники с серыми заголовками, поля и операции, подписанные зависимости и кратности. Число сущностей определяется финансовой моделью такси. Точные имена типов взяты из ЛР3: FinancialPlan, MonthParameters, FinancialCalculator, ForecastService, ComparisonService, результаты и IPlanRepository.

В ЛР2 проектируются UI и Infrastructure; их подписи не означают готовый финансовый Blazor или SQLite. Код предыдущей ЛР3, сайт заказов и ранее выданные файлы не изменены. Этот комплект — обновлённая отдельная подача ЛР2 по образцу.

## Проверки и сдача
Проверены ссылки, соответствие классов ЛР3, числовые таблицы ЛР1 и ручной проход 5000/35000/65000. Классы и ER отрендерены из PlantUML; компонентная SVG вручную выровнена по образцу. Её PUML содержит те же блоки и зависимости, автоматическая раскладка может отличаться; наличие схем не заменяет реализацию. Автоматические тесты приложения повторно не запускались: код не менялся.

Для GitLab переносить распакованные docs и при желании Word в папку ЛР2, сохраняя относительные пути. Архив сам по себе не заменяет обязательные Markdown и исходники диаграмм. Публикация на GitHub не означает сдачу или загрузку в университетский GitLab.
